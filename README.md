# 🎂 Age Calculator

Age Calculator is a responsive web application that calculates a user's exact age based on their date of birth. It provides the age in years, months, and days, along with additional statistics such as total days, weeks, hours lived, birth day of the week, and the number of days remaining until the next birthday.

## ✨ Features

- 📅 Enter date of birth (Day, Month, Year)
- 🧮 Calculates exact age in:
  - Years
  - Months
  - Days
- ✅ Input validation for invalid or future dates
- 📊 Displays additional age statistics:
  - Total days lived
  - Total weeks lived
  - Approximate hours lived
  - Birth day of the week
  - Days remaining until next birthday
- 🎨 Animated result counters
- ⚠️ Error handling with validation messages
- 📱 Fully responsive design
- ⌨️ Supports Enter key for quick calculation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📖 How It Works

1. Enter your birth day, month, and year.
2. Click the **Calculate My Age** button.
3. The application calculates your exact age.
4. View additional information including your birth day, total days lived, and time remaining until your next birthday.
